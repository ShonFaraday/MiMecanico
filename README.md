# Mi Mecánico · mimecanico.pe

Sitio web de **Mi Mecánico S.A.C.**, servicio automotriz multimarca a domicilio o en taller en Lima.

Sitio estático (HTML, CSS y JS sin dependencias ni build).

## Estructura

- `index.html`: la página completa
- `assets/img/`: fotos
- `assets/fonts/`: fuentes autoalojadas (Saira Condensed, Barlow, JetBrains Mono)
- `vercel.json`: configuración de Vercel

## Despliegue en Vercel

1. Importar este repositorio en Vercel (Add New → Project).
2. Framework Preset: **Other**. Sin comando de build. Output directory: la raíz.
3. Para el dominio: Project → Settings → Domains → agregar `mimecanico.pe` y seguir las instrucciones de DNS.
